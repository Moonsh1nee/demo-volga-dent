# Волга-Дент

Демонстрационный сайт стоматологии с пошаговой онлайн-записью. Проект студии Akimov Web. Клиника, врачи, цены, адрес и отзывы вымышлены.

## Что умеет сайт

- Главная страница: услуги и цены, врачи, технологии, отзывы, контакты.
- Запись онлайн в четыре шага: услуга, врач, дата и время, контакты. Занятые окна неактивны, выбор сохраняется при возврате назад.
- Страницы услуг и врачей, у врача видны ближайшие свободные окна.
- Список «Мои записи» с отменой.
- Светлая и тёмная тема, адаптивная вёрстка под телефон.

Серверной части нет: запись и список записей хранятся только в браузере посетителя.

## Стек

Next.js (App Router, статический экспорт), TypeScript, Tailwind CSS, Motion, React Hook Form и Zod.
